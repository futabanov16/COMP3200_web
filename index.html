X2CNet transfers human facial expressions to a humanoid robot face, then classifies each frame into one of 22 fine-grained emotion categories using a hybrid AU-based classifier.

TL;DR

We map human facial motion to humanoid robot servo commands and introduce a 22-class fine-grained emotion taxonomy — covering basic, compound, and cognitive-emotional states — each grounded in FACS Action Unit patterns. A hybrid classifier combining pattern matching and prototype-based cosine similarity turns raw control vectors into meaningful emotion labels, enabling robots to not only reproduce but also understand the expressions they perform.

Three-Stage Pipeline

From human video to robot control values to fine-grained emotion labels

1

Motion Transfer

LivePortrait extracts facial keypoints, pose, and expression from the driving video and warps a robot source image to synthesize matching facial motion.

F Appearance Extractor M Motion Extractor W Warping Module G SPADE Generator
2

X2Control Regression

A ResNet-18 mapping network converts each synthesised robot face frame (224×224) into a 30-dimensional control vector for on-robot execution.

ResNet-18 512D features FC 512 → 256 → 30 Huber Loss (δ=0.01)
3

Emotion Classification

30D controls → AU intensities (Component B) → 22-class emotion labels (Component C) via hybrid EmotioNet + cosine similarity classification.

Component B Control → 45+ AUs Component C AU → 22 Emotions γ=0.75 Power-law

Hybrid Emotion Classification

A two-component semantic interpretation pipeline converts raw control values into emotion labels through AU mapping and dual-stream classification.

Component B

Control-to-AU Mapping

30D Control Vector
→
Semantic Source Lookup
4 modes: pos / neg / abs / signed
→
Power-Law Nonlinearity
activation = valueγ, γ = 0.75
→
45+ AU Intensities
+ Binary Activations

The power-law transformation (γ = 0.75) amplifies weak signals and compresses strong ones, making the system more sensitive to subtle expressions. Each AU intensity is compared against calibrated thresholds (0.10–0.30) for binary activation.

Component C

Dual-Stream Emotion Classification

30% EmotioNet Pattern Matching

Matches binary AU activation patterns against predefined EmotioNet rules for each of 22 emotions.

Score = recall × (1 − 0.3 × precision_penalty)

+
Hybrid
Fusion
70% Cosine Similarity (Prototype)

Computes cosine similarity between the AU intensity vector and 22 learned emotion prototypes (22-dim each).

Softmax with temperature τ = 0.5

Post-Processing Rules

Smile Boost: If AU12 or AU6 > 0.15 and disgust < 0.25 → boost Happy
Negative Suppression: High smile signal suppresses negative emotions
Neutral Fallback: If all non-neutral scores < 0.15 → classify as Neutral
Temporal Smoothing: 3-frame majority filter + 5-frame minimum duration
